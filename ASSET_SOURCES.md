# 网站图片来源与历史论文素材

头像与六篇 Highlights 的研究图片由网站所有者提供。前两篇图件于 2026-10-28 按 `Revision Suggestions.docx` 中的嵌入图片更新，分别对应文档图片 1 和图片 2。只做网页所需的尺寸与格式优化，不修饰人物、不生成研究图、不改变图件数据；头像的圆形取景由 CSS 完成。原始图片和修订文档不随网站源码发布。
